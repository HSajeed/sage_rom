linearViscousStress.C:93-105  divDevRhoReff(volVectorField& U):
    - fvc::div((this->alpha_*this->rho_*this->nuEff())*dev2(T(fvc::grad(U))))
    - fvm::laplacian(this->alpha_*this->rho_*this->nuEff(), U)
  For the incompressible model, alpha_ and rho_ are geometricOneField
  (IncompressibleTurbulenceModel.H:69-70, .C constructor). In v2006
  src/OpenFOAM/primitives/one/oneI.H, operator*(const one&, const Type&)
  returns the other operand unchanged, so alpha_*rho_*nuEff() is nuEff().
  Stokes::nuEff() returns a volScalarField named "nuEff" with value nu()
  (Stokes.C:125-136).
  linearViscousStress.C:108-121 (the rho,U overload) is not called by
  pimpleFoam.
  NOTE: the task brief named Stokes.C as the location of divDev*. That is
  incorrect for v2006; Stokes.C is included only for completeness.
